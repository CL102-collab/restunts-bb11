For returning Stunts drivers

The quick guide.

Know the original game? Here are the new controls, settings, and extras to try on your next lap.

Original physics stay on by default. Desktop and DOS builds start with classic graphics and AdLib music; the browser launcher starts with HyperVision and replacement music enabled. The TempleOS edition renders 3D geometry at 640 × 400 in 16 colors and fills the 640 × 480 display with the DOS game’s intended 4:3 proportions. It uses PC-speaker audio.

Modern ports below means SDL3 builds, including browser and DOS32. Desktop means Windows, Linux, BSD, and macOS. DOS16 has the exceptions noted below.

01 / While playing

New and extended hotkeys

Q — Rewind your driving.
Hold during a race, then release to drive again from that moment. After ten seconds, rewind speed doubles. Your new driving replaces the later recording; the run is marked as modified and is ineligible for the normal high-score table.
F3 — Cycle three new chase views.
Select the original adjustable F3 camera, then press again for close, normal, and far chase views. Chase presets hide the dashboard. Cycling back restores your original F3 position and dashboard visibility; returning from another camera starts at the original view.
T — Watch from your ghost’s view.
With a ghost selected, the existing opponent-view key switches between you and the ghost. Use F1–F4 to choose the camera for either car.
F12 — Toggle HyperVision Auto.
Modern ports start at full-track, 1280 × 800 rendering and adapt quality to target 60 FPS. Press again to return to classic graphics. From a fixed preset, F12 turns HyperVision off; the next press selects Auto. DOS16 toggles the simpler extended-view SuperSight mode instead.
Shift + F12 — Choose fixed graphics quality.
Modern ports cycle Full → High → Medium → Low → Full. Full shows the whole track at 1280 × 800; High narrows the view at that resolution, Medium uses 640 × 400, and Low uses 320 × 200. From Off or Auto, the first press selects Full. Fixed presets do not adapt to load.
Ctrl + F12 — Save a PNG screenshot.
SDL3 builds only, including browser and DOS32. Save one PNG per press in the game data folder selected with --data-dir, or the current folder by default. Files are named SHOT0001.PNG through SHOT9999.PNG, skipping existing names. In browsers, screenshots go to the selected folder when writable; otherwise, or if writing fails, the PNG downloads separately from exported saves.
F11 or Shift + F11 — Show performance.
Toggle FPS and render time in modern ports, or FPS alone in DOS16. Use Shift+F11 if your browser reserves F11 for fullscreen. Works while driving, in replays, car previews, and the driving intro; some menus hide the display until you return.
Shift + F10 — Switch the music.
Modern ports switch between original AdLib and included Ogg recordings at the same song position. Use it during the intro, menus, or race-end screens; it is inactive during races. Missing recordings fall back to AdLib. Plain F10 keeps its original track-editor function.
Alt + Enter — Toggle fullscreen.
Use in desktop ports, or use the browser launcher’s Fullscreen button or Alt+Enter shortcut. Click inside the browser game first so it receives keyboard input.

Graphics and music choices last for the current session. HyperVision changes presentation without changing physics or replay data. In modern ports, F12 also works in the main menu, track preview, car-selection screens, and opponent screens.

02 / Before you start

Launch parameters

For native builds, add switches after the executable name in a terminal or shortcut. For example: restunts.exe --nointro --hv:auto --ogg:on. On Linux or macOS, use ./restunts instead.

Keep replay settings consistent. Replays do not store the physics fixes or OWOOT setting. Use the same settings for recording, playback, and ghost racing. The four legacy behaviours below default to on; use off to apply each fix.

--nointro — Go straight to the menu.
Skip the startup intro after initialization. The intro is still available when leaving the main menu. Use this exact lowercase spelling.
--hv:auto|full|high|medium|low — Start with HyperVision.
Choose one value, such as --hv:medium, in modern ports. Auto adapts quality; the other values lock a preset. The choice applies from the intro onward and can be changed with F12 or Shift+F12. Omit the switch for classic graphics; repeated or unknown presets are errors.
--ogg:on / --ogg:off — Pick the starting music.
In modern ports, on enables replacement Ogg music and off selects original AdLib, the native default. Supply this option only once. Shift+F10 can switch later; missing or broken recordings use AdLib.
--pg:off — Fix power gear and anti-power gear.
Restore the aerodynamic slowdown lost by the original power-gear bug. This changes handling and may change replay outcomes. --pg:on restores the original behaviour.
--lcb:off — Remove the left-turn advantage.
Make steering and skid-angle rounding symmetrical, removing the original stronger response when turning left. --lcb:on restores the original bias. Collision-recovery behaviour is controlled separately by --lc.
--lc:off — Enable collision fixes.
Prevent missed wall, block, and loop-base impacts; avoid false crashes in clear passages under ramps; and remove permanent steering bias after contact. --lc:on restores legacy collision behaviour for original replay compatibility.
--dws:off — Fix Dual-Way Switching penalties.
Correct penalty calculation for shortcuts between the branches of a split track. --dws:on preserves the original switching behaviour and is the default. Android and browser launchers expose this as “Dual-Way Switching”.
--owoot — Enforce One Wheel On Or Over Track.
Keep part of at least one tyre on or above the road and follow each stunt’s intended route. Under-road driving and large-corner rumble strips do not count. A single gap tile between connected, aligned ramps or bridges is allowed. A violation crashes the player, including during replay playback. Omit the switch to disable it.
--data-dir PATH — Choose the game and save folder.
In native modern ports, put this first: restunts.exe --data-dir "C:\Games\Stunts" --nointro. It changes where resources are read and saves are written. Without it, the current working directory is used. In the browser, use Choose game folder instead.
--help / -h — List supported options.
Run on its own to print the options for your build and exit. Useful when switching between modern ports and DOS16.
--version / -v — Identify your build.
Run on its own to print version and build information without starting the game. You can also see build information in the in-game Options menu.
--licenses — Read dependency notices.
Run on its own in non-DOS modern ports to print the bundled third-party notices and exit.
repldump RACE.RPL --owoot — Check a recorded run.
The separate physics dump tool writes RACE.owo with pass or fail. Passing requires a completed, crash-free run without OWOOT violations. Add the recording’s physics switches after the replay name; when checking batches, also check the tool’s exit code.

The HyperVision, Ogg, physics, and OWOOT options are case-insensitive. For each of --pg, --lc, --lcb, and --dws, the last supplied value wins. --nointro is case-sensitive. The browser launcher exposes the checkboxes described below.

03 / More to discover

Beyond the keyboard

Opponent → Clock → Ghost — Race a recorded lap.
Choose a replay to load its track, then drive in your own selected car and transmission. The silent grille ghost never collides with you, stays synchronized through rewinds and restarts, and stops at its final position. Choose Clock again to clear it; a different track, edited layout, or AI opponent also clears it. Saved replays do not include the ghost.
A bigger garage — Bring up to 120 cars.
The original 32-car limit is expanded. Keep your custom car resources in the game folder and select them through the usual car-selection screen.
HyperVision artwork — Sharper views and smoother motion.
Modern ports add interpolated motion targeting 60 FPS, car shadows, corrected visual ride height, sharper horizons, menu backgrounds, and opponent portraits. Shadows and enhanced horizons appear at 640 × 400 and above; 320 × 200 uses original horizons without shadows. Missing enhanced artwork falls back to the original.
Replay filenames — See which run you are watching.
The loaded replay’s filename appears during playback, making it easier to keep track of saved runs.
Needle colours — Customize analogue dashboards.
In CarWorks, edit the car’s “needle colour” word (Red #5). Its low byte selects the speedometer colour; the high byte selects the tachometer colour, or inherits the low byte when zero. For example, 0x040F selects palette indices 15 and 4. Digital digits are unchanged. Full format details.
Opponent videos — Add custom win and lose animations.
In modern ports, put VP8 WebM clips named opp1win.webm, opp1lose.webm, through opp6win.webm, opp6lose.webm in opponents/animations/ under the game folder. On DOS32, use opponent/anim/ with long-filename support. “Win” and “lose” refer to the opponent. HyperVision loops them with the game music; missing or unsupported clips use the original animation. Setup details.

04 / No installation needed

Playing in your browser

Choose game folder — Bring your original data.
Open the browser player, select your Brøderbund Stunts 1.1 folder (12 February 1991), then choose Start game. Files stay on your device. You can also download restunts.html and open it for offline play.
Launcher checkboxes — Set graphics, music, and intro.
Before starting, “HiperVision” selects --hv:auto and “New MIDI” enables the Ogg recordings; both are checked by default. “Skip intro” selects --nointro. Use F12, Shift+F12, and Shift+F10 to change graphics or music in game.
Export / Import — Keep your browser saves.
With read/write folder access, saves go directly into your game folder. With read-only access, use Export saves before closing the tab, then import that file before starting next time. Follow the launcher’s save-status message; tracks and replays can also be imported.

05 / Optional tuning

Desktop display and performance

These are environment variables for desktop ports. Set them before launching the game; leave them unset to use the defaults.

RESTUNTS_BORDERLESS=1 — Start in a borderless window.
Use a maximized borderless window if it presents more smoothly on your desktop. Panels or docks may remain visible. Alt+Enter still toggles fullscreen and returns to this window. Unset the variable or use 0 for the normal window.
RESTUNTS_VSYNC=0 — Disable display synchronization.
Desktop VSync is on by default in both classic and HyperVision rendering. Use 0 to disable it, or 1 to explicitly enable it. Game speed and the rendering targets stay the same.
RESTUNTS_RENDER_WORKERS=auto — Try parallel HyperVision rendering.
The default is 0 background workers. Select 1–7, or auto for the logical CPU count minus one, capped at seven. Small scenes stay serial. Try this only if it improves measured performance on your machine; physics are unaffected.

Linux/macOS example: RESTUNTS_BORDERLESS=1 ./restunts.
PowerShell example: $env:RESTUNTS_BORDERLESS = '1', then run .\restunts.exe.
